# README

The goal of this repository is to provide a from first principles derivation of the analytical solution for for the Geometric Brownian Motion Stochastic Differential Equation. Then, a discretization will be applied to derive the Euler-Maruyama method, which will be implemented, and its convergence tested. Finally, a practical application will be implemented (population growth under uncertainty).
